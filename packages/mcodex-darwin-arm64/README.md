# @m9rco/mcodex-darwin-arm64

Platform-specific transport for [mcodex](https://github.com/m9rco/mcodex). npm selects this package automatically. Install `@m9rco/mcodex` to use the CLI.

MLab Gateway 0.4.1; MIT license. The binary SHA-256 is recorded in SHA256SUMS. This package has no installation scripts and contains no user configuration or credentials.
