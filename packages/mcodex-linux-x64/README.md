# @m9rco/mcodex-linux-x64

Platform-specific transport for [mcodex](https://github.com/m9rco/mcodex). npm selects this package automatically. Install `mcodex` to use the CLI.

MLab Gateway 0.3.2; MIT license. The binary SHA-256 is recorded in SHA256SUMS. This package has no installation scripts and contains no user configuration or credentials.
